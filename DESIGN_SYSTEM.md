# Folio Design System V7 — Classic Comfort

## Product feel

Folio should feel calm, trustworthy and comfortable enough to open every day.
The design language is closer to a modern private-banking notebook than a flashy fintech dashboard.

## Palette

Light:
- Canvas: #F6F0E7
- Surface: #FBF7F1
- Elevated: #FFFCF8
- Soft: #ECE2D6
- Ink: #2A221C
- Muted: #77685C
- Coffee accent: #8A6A50

Dark:
- Canvas: #15120F
- Surface: #1C1814
- Elevated: #241F1A
- Ink: #F3EADF

## Geometry

- Small radius: 12
- Standard radius: 16
- Large surface radius: 22
- Sheet radius: 30

Avoid giant 32–40px card radii except where a native sheet genuinely needs it.

## Surfaces

Use tonal separation and thin borders first.
Use shadow only for elevated primary sections.
No glassmorphism as a default material.

## Charts

Charts must answer a question.

Trend chart:
- raw daily data = thin low-opacity line
- primary trend = coffee line
- subtle grid
- compact Y axis
- average reference line
- touch tooltip

Composition chart:
- horizontal 100% allocation band
- clear legend
- amount + percent
- no oversized donut

Cash-flow comparison:
- income / spending / remaining
- simple classic columns
- no rainbow colors

## Typography

Manrope remains the UI typeface for clarity.
Money values use tabular figures, moderate weight and compact tracking.
Do not make every title bold.

## Motion

Motion is functional:
- 150–260ms UI feedback
- chart transitions around 400–520ms
- no decorative looping animation on daily-use screens

## Copy

Calm Turkish.
No exaggerated motivation.
No visible “AI” branding unless it is materially needed.
